# Footer 3 — `g3ft01` (tema-saas-3)

## Amaç
Web sitesi alt bilgi (footer) bölümü. Logo, telif hakları, iletişim bilgileri ve sosyal medya linklerini içerir. Tüm sayfa türlerinde kullanılabilir evrensel modüldür. logo_maxh: logo tavan yüksekliği (oran korunur); logo_plate: true → logonun arkasında beyaz plaka (koyu zeminde koyu logo); contact_line: auto → setting.phone/email varsa tek satır «tel · e-posta», false → yok.
